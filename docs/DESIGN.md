# 设计说明 / Design Direction

## 定调

| 问题 | 回答 |
|---|---|
| **目的** | 让评委和路人 30 秒内看懂「麦凑单」在解决什么，并愿意去 GitHub 点 star |
| **受众** | 开发者（看得懂技术价值）+ 办公室白领（看得懂那顿饭便宜了 9 块） |
| **调性** | 玩趣 Playful —— 圆润造型、明快色块、弹性动效；但用工业级的精确排版兜住，避免幼稚 |
| **记忆点** | 首屏那张 **会实时重算的锯齿小票**：改一下谁想吃什么，上面的金额和分账当场变 |

## 字体与配色决策

**字体三件套，全部本地自托管 + 子集化，不依赖 Google Fonts**（中国区访问不稳定，首屏不能押在外部 CDN 上）：

| 用途 | 字体 | 理由 |
|---|---|---|
| 中文展示 | 得意黑 Smiley Sans | 自带倾斜骨架，斜向张力强；2.5MB → 子集化后 49KB |
| 数字/金额 | Fredoka | 圆润几何，和「食物」调性同频；金额是页面的主角，必须有专门的字 |
| 小票内容 | JetBrains Mono | 等宽 + tabular-nums，小票/收据的质感来自这里 |

正文用系统中文字体栈（PingFang SC / 思源黑体）——**正文要消失，展示字才立得住**。

**配色**：暖奶油 `#fff6e9` 作底（不用纯白），麦当劳红 `#c4231a` 作主色，蛋黄黄 `#ffc72c` 只做强调（跑马灯、highlight、路径示例线的竖条），绿色 `#1b6e48` 仅表示"省了"。按 60/30/10 分配，强调色单页不超过一种用法。

## 构成

- **首屏非对称**：左侧文字列偏窄（1.04fr vs 0.96fr），小票右倾 −1.6° 并略微冲出对齐线
- **破格元素**：满减阶梯跑马灯横穿整个视口（`width:100vw` + 负 margin 冲出 `.page` 版心），倾斜 −1.4°
- **试算控制台**：横跨版心的带状区，用一条 hairline 与首屏分隔，4 列人员选择，数字实时联动
- **锯齿小票**：`clip-path` 生成上下各 20 个齿，外层 `drop-shadow` 自动跟随裁剪轮廓

## 动效

| 类型 | 实现 |
|---|---|
| 入场 | 首屏 5 组错峰（0/80/160/240/320ms），`translateY(22px)` + opacity，`cubic-bezier(0.16,1,0.3,1)` |
| 滚动 | `IntersectionObserver` 触发 `.reveal.in`，只动 opacity/transform |
| 数字 | 金额变化时 520ms 三次缓出计数滚动，非跳变 |
| 悬停 | 路径条目左侧淡黄擦入 + 序号右移 6px；按钮 `scale(1.02)` 弹性 |
| 跑马灯 | 26s 线性无限滚动，悬停暂停 |
| 降级 | `prefers-reduced-motion: reduce` 下全部关闭，计数直接落值 |

## 自检结果

**对比度实测**（脚本计算，非目测）：

| 组合 | 实测 | 要求 |
|---|---:|---:|
| 正文 `#231a12` / 底 `#fff6e9` | 15.97 | ≥4.5 ✅ |
| 次要 `#6f5b47` / 底 | 6.01 | ≥4.5 ✅ |
| 红字 `#c4231a` / 底 | 5.44 | ≥4.5 ✅ |
| 绿字 `#1b6e48` / 纸面 | 6.18 | ≥4.5 ✅ |
| 按钮文字 / 红底 | 5.44 | ≥4.5 ✅ |
| 深底反白 / `#1e1710` | 16.55 | ≥4.5 ✅ |

**反 AI 味清单**：展示字非 Inter/Roboto/system-ui ✅／无白底紫渐变 ✅／首屏非「居中标题+双按钮+三张卡」✅／路径列表用编号 + hairline 而非同构卡片 ✅／组件覆盖 hover/active/focus-visible/checked ✅／存在明确记忆点 ✅

**响应式**：1440 / 768 / 390 三档实测无横向溢出、无构成崩坏。修复记录：移动端 `grid-template-columns: 1fr` 的 min-content 下限会把网格撑出视口，全部改为 `minmax(0,1fr)`。

**踩坑记录**：多层 `mask` + `mask-composite: intersect` 在部分 Chromium 上会让整张小票**完全渲染不出来**（不是变形，是消失）。改用 `clip-path` 后稳定，且 `drop-shadow` 会自动跟随锯齿轮廓 —— 比 mask 方案更省事。

How it computes

不算完，
不下结论。

满减阶梯四档、券若干张、四个人各点各的 —— 候选组合是几十到几百种。 与其让模型"估一个差不多的"，不如把这件事交给确定性代码。 引擎沿三条路径枚举，取实付最低者。

01

凑门槛

对每一档还没够到的满减，算出补差金额、能换回多少减免，再看净收益是否为正 —— 不是所有档都值得凑。

补 ¥6.00 → 多减 ¥15.00
净收益 +¥9.00
02

拆单

一单吃大额满减，未必比拆成两单各用一张券便宜。引擎枚举所有二分方式，分别结算后取合计更低者。

一单 ¥85.50
拆两单 ¥82.00
03

换品

同品类换更便宜的那款 —— 前提是不因此跌出当前档位。这一步经常能挤出一两块的确定性收益。

大薯 → 中薯
省 ¥2.50 不掉档
Install

两步接入，
不需要 Token 也能看。

真实下单需要麦当劳 MCP Token（官网免费申请）。但引擎本身是纯标准库 Python， 仓库自带示例数据，克隆下来就能离线跑通整条链路。

~/mcd-group-deal 
# 1. 克隆
$ git clone https://github.com/robll-v1/mcd-group-deal
$ cd mcd-group-deal

# 2. 离线看效果（不用 Token）
$ python3 scripts/demo.py

# 3. 跑引擎自测
$ python3 scripts/test_optimizer.py
